Приветствие (сервер → клиент)
s.send("WELCOME", s"${s.id}|$status")
// send делает: out.writeUTF(msgType); out.writeUTF(text)

пример: id = 3, status = "RETURNING"

writeUTF("WELCOME")   00 07  "WELCOME"
writeUTF("3|RETURNING")  00 0B  "3|RETURNING"

Дальше все сообщения от сервера идут в формате «пара строк»:
writeUTF(msgType)   // "OK", "ERR", "NEW_FILE", "FILES"
writeUTF(text)      // произвольный текст

это делает ClientSession.send

in.readUTF() match
  case "FILE" =>
    val fileName = Paths.get(in.readUTF()).getFileName.toString
    val size = in.readLong()
    IoUtil.copyExactly(in, fos, size)   // ровно size байт тела
  case msgType =>
    println(s"\n<< [$msgType] ${in.readUTF()}")   // второй readUTF — текст

Порядок чтения критичен:
    Читаем msgType (readUTF).
    Если "FILE" -> читаем имя (readUTF), размер (readLong), тело (readFully/copyExactly).
    Иначе -> читаем текст (readUTF) и печатаем.

UDP Multicast: репликация основной -> резервные
Replicator.syncAll:

val bytes = ByteArrayOutputStream()
val dos = DataOutputStream(bytes)
dos.writeUTF(f.getFileName.toString)     // 2 + N байт - имя файла (длина строки)
dos.writeLong(data.length.toLong)        // 8 байт - полный размер файла в байтах
dos.writeInt(i)                          // 4 байта — индекс куска -номер куска (с 0)
dos.writeInt(chunks)                     // 4 байта — всего кусков
dos.writeInt(len)                        // 4 байта — длина данных в этом куске
dos.write(data, from, len)               // len байт - сам кусок
dos.flush()

val packet = bytes.toByteArray
socket.send(DatagramPacket(packet, packet.length, group, Config.MulticastPort))
